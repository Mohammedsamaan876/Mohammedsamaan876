## About Me

</div>

I'm **Mohammed Samaan Jushiddi**, a Computer Science and Engineering student passionate about building useful, reliable, and visually appealing software.

My primary focus is mobile application development with Flutter, alongside modern web development, backend fundamentals, databases, and AI-powered applications.
